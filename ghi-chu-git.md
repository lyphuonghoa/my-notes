# Ghi chú về các lệnh Git

1. git init: Khởi tạo một Git repository trong thư mục dự án.

2. git status: Kiểm tra trạng thái của các tệp trong Git.

3. git add: Đưa tệp từ Working Directory vào Staging Area.

4. git commit: Lưu các thay đổi vào Repository với một thông điệp.

5. git push: Đẩy các commit từ máy tính lên repository trên GitHub.
